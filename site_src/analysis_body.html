Scientific interpretation: weighted spatial agreement, not a geological mechanism

The competition's distance-weighted Tversky index uses a triangular kernel k(d)=max(1-d/3,0), where distance is in 100 m pixels and the radius is 300 m. For each truth pixel, the best nearby prediction contributes credit no greater than one. Each prediction contributes false-positive cost according to its distance from the nearest truth. With K=|G| and TPw, FPw denoting the competition's weighted terms:

DTI = TP_w / (TP_w + 0.2·FP_w + 0.8·FN_w)
FN_w = K − TP_w
DTI = TP_w / (0.2·(TP_w + FP_w) + 0.8·K)

Thus 0.3774 is not 37.74% recall, accuracy, or trace coverage. It is a scalar trade-off between distance-weighted credit and weighted error. Since neither the scored file and its positions nor the hidden truth size and labels are public, this score cannot establish which geological layers, fault styles, mass budget, spacing, or placement strategy produced it. Nor can it show that a particular geological mechanism was discovered.

For an incremental prediction with changes c=ΔTP_w and f=ΔFP_w, the exact local improvement condition is c·(1 − 0.2·DTI) > 0.2·DTI·f. The often-quoted c > 0.2·DTI applies only to the special case c+f=1; it is not a universal per-pixel threshold. TP_w+FP_w is an effective weighted cost, not raw emission count.
