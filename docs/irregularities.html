IR-51-02The three geodetic layers satisfy no exact algebraic identity, so the invariant convention behind geod_2ndinv is not recoverable.Tested on 5,164,312 in-footprint pixels: sqrt(dil^2+shear^2) max |error| 33.8 on a field with median 19.9 (best r = 0.9934); sqrt((dil^2+shear^2)/2), sqrt(dil^2+2 shear^2), |dil|+|shear| all worse. geod_2ndinv >= |shear| holds everywhere but geod_2ndinv >= |dil| holds only 82% of the time.OPEN - Stage 1 is stated in quantile space, which is invariant to the unknown convention.
IR-51-LEAK-01Any feature derived from the catalogue is a perfect training leak in a blocked holdout.With d_cat and cat_dens in the feature matrix, in-block AUC was exactly 0.500 while the physical features alone reach 0.63; removing them recovered in-block AUC to 0.667. Cause: every training positive is itself a catalogue pixel, so d_cat == 0 for all positives and > 0 for all negatives.CLOSED - catalogue-derived columns excluded from the model, used only at emission time.

IR-51-08The file this project has been calling the training labels is byte-identical to the known-fault raster. The competition's true training labels have therefore never been available to any GEMSDOE session, and every model here is trained against the visible catalogue as a proxy.data/labels.tif and data/existing_faults.tif both have sha256 7ba308ccdc4418b31a178f4f1ef21aaa6e152e4028f2f6f64b01f7eb25ae4093 and 425,830 bytes; np.array_equal on the rasters is True. Their positive mask (60,988 px) is also identical to this session's independently derived catalogue (data/prepared/catalogue.npy). The upstream pin is the same for both: buffedlizard55-lab/GEMSDOE24 @ 07345ea0604953d7e, data/labels.tif and data/existing_faults.tif.OPEN - and it is the single biggest cap on achievable score. Either the upstream mirror saved the same blob under both names, or the two really are the same file; neither can be distinguished without authenticated access to the DrivenData data page. Consequence: no model in this repository has ever seen a single example of the target distribution. Next session's first action should be to obtain the real labels.tif and re-run the blocked holdout against it; if the mirror is simply mislabelled, everything measured here is measuring the wrong target.
